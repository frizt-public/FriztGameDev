# Сайт студии FriztGameDev

Сайт-портфолио студии браузерных игр на трёх языках (русский, кыргызский, английский): о студии, проекты со ссылками на игры и репозитории, команда с оценками, галерея и форма заявки на консультацию. **Заявки приходят в Telegram-бота.**

## Структура

```
api/
  send.js        — принимает заявку из формы и отправляет в Telegram
  status.js      — служебная страница: показывает имя подключённого бота
data/
  content.js     — проекты, команда, галерея (редактируйте здесь)
games/
  README.md      — папка для игр, которые лежат прямо в проекте (сейчас игры открываются по ссылкам)
images/          — логотип, скриншоты проектов, фото команды и галереи
.env.example     — пример переменных окружения (токен бота, chat id)
.gitignore       — что не попадает в GitHub (в т.ч. настоящий .env)
app.js           — логика сайта: язык, отрисовка, отправка формы
config.js        — данные компании: название, почта, ссылки
i18n.js          — переводы интерфейса (RU / KY / EN)
index.html       — главная страница
styles.css       — стили
package.json     — служебный файл для Vercel
```

## Что нужно заменить на своё

1. `config.js` — почта, ссылка на Telegram, ссылка на GitHub.
2. `data/content.js` — реальные проекты (ссылки `play` и `repo`), состав команды и оценки.
3. `images/` — положите свои фото и скриншоты (можно `.jpg` / `.png`, тогда поменяйте пути в `data/content.js`).

## Telegram-бот: настройка

1. В Telegram откройте **@BotFather** → команда `/newbot` → придумайте имя и username (должен заканчиваться на `bot`). BotFather выдаст **токен**.
2. Откройте своего бота и нажмите **Start** (без этого бот не сможет вам писать).
3. Узнайте свой **chat id**: напишите боту **@userinfobot** — он ответит вашим числовым id. Для группы: добавьте бота в группу и используйте id группы (начинается с `-100`).
4. Эти два значения — `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`.

> Токен — это пароль от бота. Не вставляйте его в код и не отправляйте в GitHub. Если он утёк — в BotFather: `/revoke`.

## Публикация на Vercel

1. Загрузите папку в GitHub-репозиторий.
2. На vercel.com: **Add New → Project** → выберите репозиторий → **Deploy**.
3. **Settings → Environment Variables** — добавьте `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`.
4. **Deployments → ⋯ → Redeploy** (переменные применяются только после нового деплоя).
5. Проверьте: откройте `https://ваш-сайт.vercel.app/api/status` — там должно быть `"bot_ok": true` и имя бота.
6. Отправьте тестовую заявку через форму — сообщение придёт в Telegram.

## Где «сохраняются» заявки

Каждая заявка приходит сообщением в чат с ботом, а история чата в Telegram хранится постоянно — это и есть журнал заявок. (Vercel не позволяет сохранять файлы на сервере, поэтому отдельной базы нет.)

## Локальный запуск

Страницу можно открыть двойным кликом по `index.html` (форма при этом не отправится — для неё нужен сервер). Для проверки формы:

```
npm i -g vercel
vercel dev
```

Перед этим создайте файл `.env` по образцу `.env.example`.
